# 记忆的有效性与管理

长期记忆按 owner、群聊、私聊分别存放；自动抽取、显式工具与管理台共用存储规则。管理操作仍只作用于所选会话，不把跨会话搜索结果混入模型上下文。

## 条目、画像与遗忘

- 默认召回只返回当前有效条目；`mem_search history=true` 可查过期或尚未生效的信息。经历的结束日期表示事件结束，不代表这段经历被遗忘。
- 精确去重同时核对对象；经历核对发生区间，承诺核对截止时间。已过期条目不会阻止重新记入当前事实。整理使用相同的身份边界。
- 遗忘是可恢复的状态修改，保留历史版本。相同对象、类型及规整正文的已遗忘条目会阻止后台重新写入；用户显式重新记住或恢复可以解除本次召回抑制。当前抑制是精确匹配，不能保证识别所有改写表达。
- 保存画像时关联当前有效记忆。关联条目被更正、替代、遗忘或失效后，画像暂停进入模型提示，正文保留供复核。旧画像缺少来源映射时，对条目变化采取保守失效策略。
- 当前画像仍为整段文本，因此关联是保守的整段依赖，不宣称精确到每句话。人工保存或采纳新建议会重新确认证据；采纳时同时核对画像版本和来源内容指纹。
- 未完成承诺独立于画像显示；记录截止时间不会自动创建定时提醒。

## 自动抽取与冲突

抽取提示给出每条用户消息的 ID，候选必须引用本轮消息；证据片段必须存在于对应原文。单条输入允许兼容未返回来源 ID 的旧模型输出，多条输入缺少来源时不猜测最后一条。助手回答仅作上下文，助手承诺由显式工具记录。模型自报置信度只用于候选过滤，不代表经校准的事实概率。

抽取只能替代本次提供给模型、且版本未变化的自动条目。与显式记录冲突时进入待确认列表，由管理员选择更正或保留；确认时再次核对目标版本。重复抽取补充证据，不增加实际召回计数。人工编辑、确认已有自动条目或恢复历史版本后，该条目按显式记录保护；冲突确认保留候选的来源片段。

抽取队列使用持久领取租约，模型或存储临时失败后延迟重试，最多三次；超时的晚到结果不落库。终态保留收据，防止重新入队。每日调用预算仍为每会话 200 次，重试也计入预算；无效 JSON、关闭抽取、短输入和额度用尽保留明确跳过事件。

## 查询与管理界面

精确字面搜索优先完整匹配及显式记录，不按历史召回时间持续抬高旧命中。完整问句查不到时，使用最多六个关键词检索，按共同命中数合并，明确标记为关键词相关结果；尚未引入向量索引。召回事件仅保存条目 ID、数量与降级标记，不保存用户查询正文。

记忆页支持 ID、类型、状态、有效时间、写入方式筛选，以及新增、编辑、完成承诺、遗忘和恢复。详情展示来源、画像关联、替代关系和版本差异；原始 JSON 收入折叠详情。模型操作区分生成、跳过、失败和部分完成，失败或中断整理也可以回滚尚未被后续修改的条目。

页面请求绑定会话与递增请求编号，旧响应不能覆盖当前会话。编辑和遗忘携带条目版本。画像编辑保留当前页内草稿，遇到并发修改时同时显示已保存版本供比较；退出登录会清除草稿。

## 兼容与验证

新增表与触发器独立追加，不改动已部署 Durable Object 的迁移历史、记忆 ID 或历史快照格式。管理投影包含来源和待确认记录；执行线程的 alarm 仍先派发已准备好的模型请求。

行为测试覆盖跨对象去重、时间有效性、遗忘与画像失效、过期建议拒绝、来源核验、同秒并发修改、冲突确认、持久重试与关键词召回。DOM 测试运行真实页面模块，覆盖乱序响应、带版本的编辑与遗忘、画像冲突草稿以及模型超时反馈。
