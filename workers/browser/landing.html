HYBRID COMPUTE

给不同风险的活，
分配最合适的一台机器。

轻量代码与文件检索直接在 Cloudflare 容器按需运行；需要用现成开发环境或桌面 GUI 时，通过反向 WebSocket 桥派给主人电脑或持久 VM；遇到来历不明的安装包或脚本，扔进一次性 Windows Sandbox 用完即焚。

自己的电脑 一行脚本主动 443 连出，管理台按会话精确勾选哪台设备可用。
云端容器 免运维 Linux 环境，R2 去重快照保留项目工作区，空闲 3 分钟休眠。
一次性沙盒 同 session 复用、取消即销毁，独立 Guardian 守护防失控超时。

COMPARE

为什么不直接在群里
挂个普通 Bot 或裸调 CLI？

在聊天软件里接个 Webhook 很容易，但一旦涉及 Serverless 长连接超时、多步工具编排、群聊凭证隔离和断连防重放，普通做法就会频频掉链子。

只在 HTTP 请求里同步转发模型和工具，连接超过平台限时就会中途断掉。

维度
普通聊天 Webhook Bot
Joule

什么时候选它：只需要无状态一问一答、不涉及私有凭证和长耗时构建时，普通 Webhook 更省事。
